Tools

Deck authoring helpers. Not part of the flashcard site — used to prepare decks.

CSV → JSON & Markdown

Paste CSV with a header row (e.g. key;frontText;frontDetails;backText;backDetails;category). Each row becomes a card object and a Markdown line: 🔸 **frontText frontDetails** - backText.

Vocabulary search

Enter German words or expressions, one per line. Each is looked up in a vocabulary.csv by frontText; matches are replaced with their full CSV row, in the same order you typed them. Words with no match are left as-is.
