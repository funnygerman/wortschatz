Tools

Deck authoring helpers. Not part of the flashcard site — used to prepare decks.

CSV → JSON & Markdown

Paste CSV with a header row (e.g. key;frontText;frontDetails;backText;backDetails;category). Each row becomes a card object and a Markdown line: 🔸 **frontText / frontDetails** - backText.

Markdown → CSV

Paste already-published lines like 🔸 das Schaf / die Schafe - овца (the ✱✱bold✱✱ markers are optional — plain-text copies work too, and -/–/— are all accepted before the translation). Each line becomes a CSV row. The key column is filled from frontText and backText, by calling the actual rule the player uses when a deck omits the key — imported live from v2/src/key.js in funnygerman/flashcards, not a copy of it. Lower-cased and hyphenated, the article dropped from a noun, a card's own script kept as written (fünf stays fünf, чем stays чем). Both sides, so the two laufen cards no longer collide on one key.

Preview & edit

Load a vocabulary.csv (or paste one, or send it here from another tab), then edit cells directly in the table — category offers the existing categories as suggestions. Every edit updates the raw CSV underneath; switch to "Raw CSV" any time to copy it out or paste a whole new version in and apply it back to the table.

Fill blank keys writes a key into every row that has none, by the same rule the player uses for a card that omits it. It never touches a key that is already there — that is the point of it. A key belongs to a row from the moment it is written: readers' schedules live in their own browsers under these keys, so a key that shifts because a translation was reworded doesn't correct that card, it abandons it. Fill once, when you add the row, and the key stops moving. Duplicates are reported rather than fixed, since which of two identical rows is the real one is not something a rule can know.

If you do have to change a key that is already in use — a typo baked into it, an old front-only key you want in line with the rest — just edit the cell. The old key is recorded in a wasKey column (added to the CSV only when a rename actually happens, several keys separated by |, newest first). The player reads it and moves that reader's schedule and dictionary entry across on their next visit, so a renamed card keeps the box it earned instead of arriving as a card nobody has ever seen.

Vocabulary search

Enter German words or expressions, one per line. Each is looked up in a vocabulary.csv by frontText; matches are replaced with their full CSV row (all of them, if a word has more than one entry), in the same order you typed them. Words with no match are left as-is.
